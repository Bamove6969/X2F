Draft copy

Settings › Profile visibility. One switch, off by default for every account (opt-in); this board shows it switched on so the preview has something to show. It applies straight away, so there is no Save footer. The preview under it is live: it shows the exact line other traders will see, or a dashed "nothing shown" row when the switch is off. The total tweak swaps the example total to check the rounding.
