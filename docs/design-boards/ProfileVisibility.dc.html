Design notes

Draft copy

Settings › Profile visibility. One switch, off by default for every account (opt-in); this board shows it switched on so the preview has something to show. It applies straight away, so there is no Save footer. The preview under it is live: it shows the exact line other traders will see, or a muted "nothing shown" row when the switch is off. The total tweak swaps the example total to check the rounding.

Decided · owner, 6 Nov (Q63)

The line shows the amount in XMR traded to date, not dollars. X adds buying and selling. This replaces the 2 Nov dollar steps ($10,000 to $90,000, then $50,000 steps).

Rounding, design call: down to one decimal. It is a reputation figure, not an amount being moved, so the 6-decimal rule for amounts does not apply, and rounding down never overstates.

Decided · owner, 7 Nov (G54) "Traded to date" counts X2F trades only. Imported volume stays on its own lines, one per site. Q64 (6 Nov) already put imported volume on a per-site line ("Imported from LocalMonero: 120.0 XMR"); it never adds into the X2F total. The example above follows this: mira.k's 41.7 XMR is X2F only, and the LocalMonero import sits under it on its own line. The imported line is drawn only when the volume switch is on and there is a verified import.
