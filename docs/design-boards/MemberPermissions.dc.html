Design notes

Decided · owner, 6 Nov (Q16)Team permissions are granular: member types with checkboxes
  • Three or four member types. Each type has 7 to 10 checkboxes the owner ticks one by one.
  • A member can belong to several types, or all of them, with only some boxes ticked in each.
  • This replaced the four presets. The board is now redrawn to this model (7 Nov): four types, each with its own checkboxes.

Types. Each type is a card with a disclosure header (64px): name, count, and a switch on the right. Switch on = desk_ana is in that type; the card opens to its checkboxes (44px rows, 22px boxes, ink accent). Switch off = the card closes and greys out. Its ticks are kept but disabled, and don't count, until the type is switched back on. Any card can still be opened to look. Sensitive. Release XMR carries a SENSITIVE chip. Ticking it asks first (owner rule, 2 Nov: sensitive permissions ask when turned on), then shows the caution callout under the row. Switching on a type that already has it ticked asks too. Count. The summary counts only the ticks in types that are on. Tweak example: offers-and-chat, everything, trades-with-release.
