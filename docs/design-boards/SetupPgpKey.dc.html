Add your PGP public key

Paste the public key from your PGP app. X2F never asks for your private key, so don't paste it here.

We accept RSA keys of 4096 bits or more, Ed25519 and Ed448. If a key has expired or been revoked, we'll tell you. This is an example key.

If your key carries contact details, X2F never shows or uses them. For full privacy, use a key without any.

You cannot create your PGP key with X2F, because that would put your private key at risk. Read the FAQ for more help.
