Design notes

Header: logo D (owner, 8 Nov, page 8); in the wide rail the page name sits under the logo so it never cuts off (comment #2).

  • Craft pass, 7 Nov: queue counts are KPI cells (40 icon tile, uppercase label, mono 28 value) toned by meaning: overdue danger, unassigned caution, second approval mod.

  • The empty filter state uses the shared empty state (56 tile flanked by two small blocks, escrow and caution). Its second sentence is COPY-UNSIGNED.
