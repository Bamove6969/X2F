Design notes

Shared component One popup for every "not allowed" moment. Builders swap in the explanation; everything else stays the same.
  • Title: sheet title, Familjen 24/30 700.
  • Explanation: one or two plain sentences, 16/24 ink. Example shown: the offer limit.
  • Feedback line: info callout (surface-raised, radius 12, 18 px chat icon, v2 §12) with the link to Feedback.
  • Craft pass, 7 Nov: digits in the explanation are set in mono (the message is split into parts, so builders can swap any sentence in).
  • OK: the one orange button (wide: 48 high, min 160, right-aligned), closes the dialog. No close X.
  • Wide: centred dialog, 480 wide, padding 28, radius 16, 1px surface-raised border over the scrim. Phone: bottom sheet.
