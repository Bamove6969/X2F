# Dev setup

- **Node 22.23.3** via nvm (`nvm install` reads `.nvmrc`; on this machine it lives at `~/.nvm/versions/node/v22.23.3`). `tools/check.sh` uses the PATH node if it is v22.x, else the nvm path, and fails clearly otherwise. Node 20 is end of life.
- **Install dependencies** with `npx -y npm@11.21.0 install --save-exact` (older npm crashes on the vitest 5 peer set). `package-lock.json` is generated by this npm.
- **Semgrep 1.178.0** in `~/.local/semgrep-venv` (`python3 -m venv ~/.local/semgrep-venv && ~/.local/semgrep-venv/bin/pip install semgrep==1.178.0`). Semgrep scans only git-tracked files: `git add` new files before `npm run check`.
- Run everything with `npm run check` (typecheck, tests, `npm audit --omit=dev`, Semgrep).
- Keep `apps/.gitkeep` until `apps/relay` exists (Semgrep errors on empty scan roots).
