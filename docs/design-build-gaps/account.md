## 3. Summary

1. Roughly half the boards in this area have no screen at all: the Settings hub and everything it leads to (Account type / BecomeVendor, Alerts preferences, Delete account, Session length and extend, Support, FAQ), the whole hold/recovery family (RecoveryCode step, RecoveryHold, Compromised, HoldChange) and the team family beyond a basic list (MemberPermissions, MemberApproval, TeamRefusal, TeamChat attribution, OwnerSetup).
2. Where a screen exists it is a flat `.x2f-screen` stack of bordered 12px cards with an 18px title and no back/context line, while every board uses the v2 frame: 44px back + context + 28/32 Familjen title, 16px-radius borderless cards, hero washes for the key moment and a pinned footer primary.
3. The shared kit is largely absent from the build: no login-method seals, no strong-login seal trio, no trader/team identity rows (avatar, online dot, Vendor/Team member tags, blocked marker), no 40px icon tiles on meaningful rows, no stat tiles, no labelled setup stepper, no designed done/empty states; lists are bare text rows with text buttons.
4. Several boards encode owner decisions the build contradicts: recovery code is the only backup (build also offers TOTP), one private username at signup (build asks for a public username plus a login name), per-member permission types (build has two roles), partner-facing chat never names the member (build plans to), signup offers an authenticator-only login option.
5. Tokens drift at the root: Monero is #ff7a1a/#f26822 in the build vs #ff6600 on every board; countdowns are mm:ss instead of mono digits with body units; wide layouts have no nav rail or 24px two-column grids, and wording drifts in small ways on almost every screen (listed as P4 above, owner to decide).
